Overview

SNS Detox is a browser extension that blocks distracting content on YouTube and Reddit. Your privacy is important to us. This extension is designed to operate entirely on your device with no data collection, no tracking, and no external data transmission.

Data We Collect

None. SNS Detox does not collect, store, or transmit any personal data.

Data Stored Locally

The extension stores the following configuration data locally on your device using the Chrome storage.local API:

  • Platform blocking preferences (YouTube / Reddit enabled/disabled)
  • Section-level toggles (e.g., block Home feed, hide Shorts navigation)
  • Schedule settings (time ranges, days of week for scheduled blocking)

This data never leaves your device. It is not transmitted to any server, third party, or analytics service.

Website Access

The extension runs content scripts on youtube.com and reddit.com solely to:

  • Inject CSS to hide distracting content sections
  • Display a blocking overlay when content is scheduled to be blocked

The extension does not read, collect, or transmit any page content, browsing history, user activity, or any other data from these websites.

Permissions

  • storage - Save your blocking preferences locally on your device
  • alarms - Trigger scheduled blocking at configured times
  • Host permissions (youtube.com, reddit.com) - Inject content-blocking CSS into these sites

Third-Party Services

The extension loads Google Fonts (Inter, Quicksand) for the blocking overlay display. This is a CSS-only resource. No user data is shared with Google through this request beyond the standard HTTP headers sent by your browser.

Data Sharing

We do not sell, transfer, or share any user data with third parties for any purpose.

Children's Privacy

This extension does not knowingly collect any information from anyone, including children under 13.
